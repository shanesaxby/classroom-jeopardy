# Quick GitHub Pages setup

1. Create a repository named `classroom-jeopardy`.
2. Upload every file and folder from the Version 2 package to the repository root.
3. Confirm that `index.html`, `game.js`, `styles.css`, `.nojekyll` and the `quizzes` folder are visible at the root.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. Wait for the deployment to complete and open the published address shown by GitHub.

To add permanent quizzes later, add the JSON and images to `quizzes/`, update `quizzes/quiz-list.json`, and commit the changes.
